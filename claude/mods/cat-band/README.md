# cat-band

A Claude Code mod: a small ASCII cat sits above the prompt. It walks back and
forth while Claude is working and naps (with drifting `z Z`) while idle.
`/cat` hides it or brings it back.

Run it for a session with:

```sh
claude --plugin-dir ~/workspace/personal-setup/claude/mods/cat-band
```

or load it in every session by adding the folder to `CLAUDE_CODE_PLUGIN_DIRS`.
